# Current weak-area recommendations

The dashboard now uses the latest committed diagnostic or rewrite assessment for
each owner/grade/subject/chapter/concept. A successful rewrite or later diagnostic
clears the current flag; guided practice alone does not. A later failed assessment
reactivates it. Historical attempts are retained and weekly response accuracy is
unchanged. Android uses dashboard recommendations rather than replacing them with
the weekly historical error summary.

The regression covers wrong answer, correct practice, successful explanation,
cross-grade isolation and a later recurring mistake. The existing full learning
loop expectation now requires no unresolved flag after successful remediation.

This is a current-focus heuristic, not proof of durable mastery. Concept identity
uses normalized text within a chapter; semantic IDs, retention checks and educator
calibration remain future work. Device-level dashboard acceptance and user UAT
are not claimed by automated backend/build checks.
