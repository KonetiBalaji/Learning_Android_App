# Saras three-minute demo

Use a disposable account, the local server in local practice mode, and the sample file in `shared/sample-study-material.txt`. Prepare the public local models first. Keep a completed sample session and one due flashcard available as backup if you need to move ahead.

| Time | Show | Say |
|---|---|---|
| 0:00–0:35 | Upload the sample and select Chapter 1. | “Saras turns material you provide into chapter-based practice. Here I’m working with the Cells chapter.” |
| 0:35–1:15 | Start a one-question quiz. Give an incorrect answer, open its source, then finish. | “The feedback shows the answer and the passage that supports it. I can revisit the mistake directly from the result.” |
| 1:15–1:55 | Open the adaptive recommendation and create or review a flashcard. | “Practice recommendations use recent results. Flashcards schedule another review based on how well I recalled the answer.” |
| 1:55–2:35 | Open a saved document, enable airplane mode, complete one question, then reconnect and sync. | “A saved document can generate questions offline. On reconnect the server validates the completed session before adding it to progress.” |
| 2:35–3:00 | Ask the document tutor about mitochondria and open its cited passage. | “The local tutor can point to related text and cite the source. Live AI explanations and difficulty evaluation await provider setup.” |

Use `shared/sample-study-quiz.json` as the frozen answer sheet. Live local generation may select a different passage or order the choices differently. The sample is synthetic study material and uses no private document.
